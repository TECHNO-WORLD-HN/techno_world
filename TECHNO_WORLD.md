# TECHNO WORLD — Landing Page

## Descripción
Página web corporativa y landing page para **TECHNO WORLD**, empresa de soluciones tecnológicas y soporte TI en Catacamas, Olancho. Diseñada con un estilo tecnológico minimalista, Tailwind CSS (vía CDN), Vanilla CSS (`assets/css/estilos.css`) y JavaScript nativo, con fuerte enfoque en experiencia móvil (*mobile-first*).

## Tecnologías y Características Clave
- **Tailwind CSS** vía CDN + Sistema de diseño CSS en `assets/css/estilos.css`
- **Google Fonts**: *Plus Jakarta Sans* (encabezados) + *Inter* (lectura)
- **Ionicons** v7.1.0 (iconos SVG)
- **Canvas API**: Malla de red de nodos conectada e interactiva
- **Intersection Observer**: Animaciones Reveal optimizadas
- **Modo Oscuro / Claro**: Persistencia automática en `localStorage`
- **UI/UX Móvil**: Menú Drawer con glassmorphism, barra flotante inferior y formulario táctil ergonómico
